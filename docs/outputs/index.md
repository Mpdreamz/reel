# Outputs

```
Output musicbox.mp4
Output musicbox.gif
Set Profiles github, social
```

`Output <path>` names a file to write: `.mp4` or `.mov` (a movie with sound) or `.gif` (no sound). A reel needs at
least one, and every output comes from the same recording.

| | |
|---|---|
| [Quality and size](quality-and-size.md) | Quality, codec, width, frame rate, and fitting under a size limit. |
| [Framing](framing.md) | The recording on a background, in 16:9, 1:1 or 9:16. |
| [GIFs](gifs.md) | Width, frame rate and colours. |
| [Profiles](profiles.md) | Every output once for GitHub, social feeds, your site, and more. |
| [Presets](presets.md) | Settings and profiles shared between reels. |
| [Conditions](conditions.md) | A value that differs by profile or output type. |
