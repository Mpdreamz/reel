# reel brand kit

- logo/svg, logo/png: symbol (detail cut, 48 px and up), symbol-small (16 to 32 px), wordmark, horizontal and stacked lockups. Suffix: dark (on Ink or Slate), light (on Paper), black, white. Wordmark is outlined Jost 500, no font needed.
- icons: favicon.svg (switches colour with the browser theme), favicon.ico (16/32/48), apple-touch-icon.png, avatar-512.png, app-icon-1024.png and reel.iconset (run `iconutil -c icns reel.iconset` on a Mac).
- line-icons: 14 icons on a 24 px grid, 1.75 stroke, round caps. sprite.svg holds them all as symbols (id reel-*).
- themes: tokens.json / tokens.css, a Ghostty theme and a VS Code theme. The VS Code theme assumes tape token scopes such as keyword.command.tape; rename to match your grammar.
Fonts (all SIL OFL): Jost, Instrument Sans, JetBrains Mono.
